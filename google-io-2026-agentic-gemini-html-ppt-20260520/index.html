02｜一句話結論

從 AI assistant 到 AI agent

Google I/O 2026 的核心不是「更會聊天」，而是讓 AI 能理解目標、拆解任務、使用工具、追蹤狀態並完成工作。

02
  • 代理人時代
  • 跨工具流程
  • 可監督執行
這頁先定調：AI 不只是回答問題，而是開始參與工作流程。這也是後面所有模型、工具、搜尋、Workspace、Shopping 更新的共同方向。
03｜全景圖

六層技術堆疊

Google 把模型、基礎建設、開發工具、產品代理與新終端串成一套完整生態。

03
  • TPU 8t/8i
  • Gemini 3.5 / Omni
  • Antigravity / AI Studio
  • Search / Spark / Workspace
  • Android XR
這是整場 I/O 的地圖。底層是 TPU 與模型，中層是 Agent 平台與開發者工具，上層則進入搜尋、購物、Workspace、YouTube 與 XR。
04｜模型升級

Gemini 3.5 與 Gemini Omni

Gemini 3.5 Flash 主打 coding、agentic、multimodal；Gemini Omni 則朝「任何輸入產生任何輸出」前進，首波聚焦影片生成。

04
  • Gemini 3.5 Flash：速度/成本/代理能力
  • Gemini 3.5 Pro：持續測試
  • Gemini Omni：文字/圖像/音訊/影片輸入
  • 影片輸出與可編輯性
模型層的重點是：Flash 不再只是便宜快，而是能支援代理工作；Omni 則把多模態生成往影片與真實世界理解推進。
05｜開發者平台

Antigravity 2.0：agent-first development

Antigravity 2.0、CLI、SDK 與 Managed Agents，把開發流程從「AI 幫忙寫 code」推向「AI 管理 workflow」。

05
  • Specialized subagents
  • Terminal sandboxing
  • Credential masking
  • Hardened Git policies
  • Managed remote sandbox
這是對技術團隊最重要的發布之一。企業真正需要的不是單一 coding assistant，而是可以安全執行、隔離、審計、回滾的代理式開發流程。
06｜AI Studio

Google AI Studio 變成 app/agent 入口

AI Studio 加入 Kotlin、Workspace、Firebase、Cloud Run 與 Antigravity 匯出，讓原型到部署更短。

06
  • 原生 Kotlin 支援
  • 一鍵部署 Cloud Run
  • Firebase services
  • Workspace integrations
  • 匯出到 Antigravity
這代表 Google 想把 AI Studio 從模型 playground 變成真正的開發入口，讓企業快速做 POC，再接到部署與代理平台。
07｜Android / Web

開發鏈全面 agent-ready

Android CLI、Migration Agent、WebMCP、Chrome DevTools for agents，讓 AI 代理人可以更穩定地操作、測試與優化 app/web。

07
  • Android CLI 供 LLM 呼叫
  • 跨平台 migration
  • WebMCP structured tools
  • DevTools 給 agents 做驗證
  • HTML-in-Canvas API
這一頁的重點是「工具被設計成給 AI 用」。未來網站和 app 不只要給人操作，也要提供結構化工具讓 agent 安全操作。
08｜消費產品

Gemini Spark、Daily Brief、Search Agents

Google 把代理能力放進日常產品：Spark 可完成工作，Daily Brief 整理優先事項，Search agents 可 24/7 追蹤主題。

08
  • Spark：個人主動式代理
  • Daily Brief：Gmail/Calendar/Tasks 摘要
  • Search information agents
  • Persistent dashboards / trackers
對一般使用者來說，AI 會從聊天框變成背景任務系統。它會追蹤、整理、提醒，但也代表權限與資料治理更重要。
09｜商業與內容

Shopping、Workspace、YouTube、Play 全面 AI 化

Universal Cart、Gmail Live、Docs Live、Ask YouTube、Play AI discovery，會改變電商、內容曝光與 app 發現方式。

09
  • Universal Cart：跨產品購物車
  • Gmail/Docs Live：語音互動文件
  • Ask YouTube：影片內問答
  • Play Shorts / Ask Play
  • 多入口導流重分配
商業影響很直接：流量入口被 AI 重組。電商、內容平台、App 開發者都需要思考：我的資料與商品是否能被 agent 正確理解與引用。
10｜新終端

Android XR 與 Android Halo

Google 重新推進智慧眼鏡與代理狀態 UI：讓 AI 工作進度在手機與穿戴場景中可見、可監督。

10
  • Audio glasses / display glasses
  • Samsung + Qualcomm
  • Gentle Monster / Warby Parker
  • Android Halo：agent 工作狀態
  • 跨 Android / iPhone 搭配
新硬體不是單純酷炫，而是為代理人提供新的互動入口。未來現場維修、客服、教育訓練、導購都有延伸可能。
11｜企業影響

企業導入 AI Agent 的四個關鍵

企業要看的不是模型多強，而是流程是否可控、資料是否可用、權限是否清楚、成本是否可預測。

11
  • Productivity：開發/客服/報告
  • Governance：權限/審計/人審
  • Risk：資料外洩/幻覺/越權
  • Opportunity：新 UX/電商/內容治理
這是給管理層的重點。AI Agent 會提升效率，但沒有治理就不敢放大；有治理，才可能變成企業級能力。
12｜建議行動

接下來 1–2 週的實作清單

先做小型驗證：追蹤 Gemini API、測試 AI Studio/Cloud Run、評估 Antigravity，並建立 AI agent governance checklist。

12
  • 追蹤 Gemini 3.5 / Omni API
  • 測試 AI Studio → Cloud Run
  • 評估 Antigravity CLI/SDK
  • 整理 sandbox / credential / Git policy
  • 規劃 agent-ready Web/API
結尾收斂到行動。不要只停在看發布會，應該馬上挑 1–2 個場景做 POC，並同步建立治理清單。
